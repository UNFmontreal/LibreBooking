MRI cron jobs and helpers
~~~~~~~~~~~~~~~~~~~~~~~~~

Settings
  The MRI settings are the configuration of the LimesurveyScreeningPre plugin
  (plugins/PreReservation/LimesurveyScreeningPre/LimesurveyScreeningPre.config.php). The pre-reservation plugin, the
  post-reservation plugin and the cron jobs all read it. Set them in that file or through the administration
  configuration page. The texts of the emails and messages, and the labels of the settings, are in plugins/MRI/lang.

Plugins
  Enable the MRI plugins in config/config.php:
    $conf['settings']['plugins']['PreReservation'] = 'LimesurveyScreeningPre';
    $conf['settings']['plugins']['PostReservation'] = 'MRIPostRes';

Files
  MriCronBootstrap.php
      Shared start-up of the cron jobs (command line only).
  MRICRON_valid_screening.php
      Marks reservations as Created once their screening is completed in LimeSurvey.
  MRICRON_reminder_screening.php
      Emails the owner of an upcoming reservation until the screening is completed.
  MRICRON_reminder_logbook.php
      Reminds the MRI operator to complete the logbook entry of a finished reservation.
  MRICRON.php
      Legacy cron. It does not load: line 370 has a syntax error and it includes MRI.functions.php, which was removed. It holds the
      reservation colour rule for screened reservations, which the jobs above do not set.

Scheduling (command line only; the scripts refuse web requests)
  php plugins/MRI/MRICRON_valid_screening.php          (every hour)
  php plugins/MRI/MRICRON_reminder_screening.php       (once a day)
  php plugins/MRI/MRICRON_reminder_logbook.php         (once a day)
